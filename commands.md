# Commands Used

## Update the Server

```bash
sudo dnf update -y
```

## Install Apache

```bash
sudo dnf install httpd -y
```

## Start Apache

```bash
sudo systemctl start httpd
```

## Enable Apache

```bash
sudo systemctl enable httpd
```

## Check Apache Status

```bash
sudo systemctl status httpd
```

## Edit Website

```bash
sudo nano /var/www/html/index.html
```
